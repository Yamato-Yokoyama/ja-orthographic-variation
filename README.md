# ja-orthographic-variation


**問い（仮）**：日本語の表記ゆれ（同じ語の書き方だけの違い）を種類別に分けたとき、多言語の埋め込み検索の精度は、どの種類でどれだけ落ちるか。英語の書き方違いと比べてどうか。

**位置づけ**：Google Student Researcher 2027（締切 2026-12-13）に出すための小さな研究。ML塾（cl-agent の `projects/ml/jp-product-search-eval`）の評価の仕組みを土台にする。

## なぜやるのか（3行）

1. 日本語は、同じ語を漢字・ひらがな・カタカナ・送り仮名違い・全角半角などで書ける。どれも正しい日本語
2. 検索は辞書と単語一致から、埋め込み（ベクトル）に移った。「埋め込みになって、書き方の違いは自然に吸収されるようになったのか」はまだ答えが出ていない
3. 2025年の言語処理学会の研究は同義語の置き換えを試し、送り仮名やカタカナの揺れは「今後の課題」としている（要・本文確認）。英語では誤字への頑健性、他の言語ではローマ字化の研究がある。**日本語の書き方の違いを種類別に分けて測った研究は見当たらない**

## 何をするのか（1行）

Amazon の実際の検索クエリ（ESCI の日本語）を、意味を変えずに書き方だけ種類別に書き換え、元のクエリと比べて nDCG@10 がどれだけ落ちるかをモデルごとに測る。

## 対象と対象外

| 対象（表記ゆれ） | 対象外（先行研究として参照だけ） |
|---|---|
| 漢字 / ひらがな、送り仮名、カタカナの揺れ、英字 / カタカナ、全角 / 半角、異体字 | 同義語への置き換え（別の語になる）、誤字（書き間違い）、文字化け（エンコーディングのバグ） |

言語は**日本語が中心、英語は比較用**。ドイツ語は必要なら一例だけ。
